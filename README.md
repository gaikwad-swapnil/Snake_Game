# 🐍 Classic Snake Game in Java

A 2D Snake game built using Java Swing and AWT graphics[cite: 4, 5]. This project features clean graphics rendering, real-time score tracking, and smooth key controls[cite: 4].

Developed by **Swapnil Gaikwad**[cite: 5]

---

## 🌟 Key Features

* **Real-time Score Counter:** Displays your current score continuously as you eat apples[cite: 4].
* **Instant Restart:** Press **'R'** on the Game Over screen to quickly launch a new round without restarting the app[cite: 4].
* **Pure Swing Graphics:** Built with standard Java graphics libraries no external PNG assets or extra dependencies required[cite: 4].
* **Collision Detection:** Wall and self-collision handling that stops movement and triggers the Game Over screen[cite: 4].

---

## 🎮 How to Controls & Play

| Key | Action |
| :--- | :--- |
| **Arrow Keys** | Change Snake Direction (Up, Down, Left, Right)[cite: 4] |
| **R Key** | Restart Game (When Game Over screen appears)[cite: 4] |
