# 🐍 Classic Snake Game in Java

A 2D Snake game built using Java Swing and AWT graphics. This project features clean graphics rendering, real-time score tracking, and smooth key controls.

Developed by **Swapnil Gaikwad**

---

## 🌟 Key Features

* **Real-time Score Counter:** Displays your current score continuously as you eat apples.
* **Instant Restart:** Press **'R'** on the Game Over screen to quickly launch a new round without restarting the app.
* **Pure Swing Graphics:** Built with standard Java graphics libraries no external PNG assets or extra dependencies required.
* **Collision Detection:** Wall and self-collision handling that stops movement and triggers the Game Over screen.

---

## 🎮 How to Controls & Play

| Key | Action |
| :--- | :--- |
| **Arrow Keys** | Change Snake Direction (Up, Down, Left, Right) |
| **R Key** | Restart Game (When Game Over screen appears). |
